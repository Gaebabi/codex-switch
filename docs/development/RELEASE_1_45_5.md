# Release 1.45.5

Windows status observation supports the specifically examined native stream 11/13 and queue 2/3 contracts. Current Codex 26.1111 counters and settings RPC recover without replacing unavailable readings with zero. Nested queued client identities participate in deduplication; unknown versions, malformed/conflicting metadata and foreign owners remain rejected.

Models moves to the titlebar, Add precedes Refresh on the toolbar, and Date chats is inside Settings. Provider, drive and history panels share caption/section/input/metric scales, model/folder tables and consistent gauges. The repository adds factual status badges and clearer installation/contribution entry points. [Actual native before/after and component evidence](../evidence/desktop-polish/README.md).

Visible folder work shares at most 32 metadata batches/allocation lookups per second and at least four query-times of rest before the next query. Initial scans, watcher setup and failed queries use that schedule; cache hits remain free of new I/O and waits cancel. A capacity-adjacent spinner identifies only the measured drive. Hiding/minimizing pauses recursive allocation work while lightweight counters continue. Full allocated size, sparse/compressed storage, hard-link deduplication, reparse exclusion and explicit missing/partial states remain supported. This bounds Switch scheduling, not whole-volume utilization.
