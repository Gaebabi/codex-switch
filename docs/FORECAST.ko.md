# 소진 예측 공식 — 1.12

예상 시간은 **현재 남은 잔량을 최근 사용 패턴으로 계속 소비할 때 필요한 시간**입니다. 미래에 언제 다시 사용할지는 관측할 수 없으므로, 예상 시각도 지금 사용을 이어간다는 조건으로 계산합니다. 쉬는 동안 잔량을 임의로 감소시키거나 소진 상태로 바꾸지 않습니다.

## 입력 구간

- 계정·한도·소비 구간별로 기록을 분리하고, 현재 구간의 최근 24시간만 사용합니다. 사용량이 감소하거나, 이전에 관측한 리셋 시각이 지난 뒤 새 시각이 보고되면 새 구간입니다. 서버의 리셋 시각 보정 자체를 구간 ID로 사용하지 않습니다. 기존 기록에 잘못 분리된 구간도 관측값에 따라 다시 연결합니다.
- UTC 시계에 고정된 10분 구간을 만듭니다. 최대 5분 간격의 실제 관측값 사이를 선형 보간하며, 10분 전체가 관측된 구간만 속도 학습에 사용합니다.
- 사용량 증가가 0인 구간은 쉬거나 다른 계정으로 전환한 시간일 수 있으므로 학습 속도를 낮추지 않습니다. 일부 사용이 포함된 10분 구간 안의 휴식은 구간 속도에 반영됩니다.
- 증가한 구간이 3개 이상이고 총 증가량이 0.1%p 이상일 때 예측을 시작합니다. 최신 조회가 15분 이상 오래됐거나 리셋이 도달하면 예측을 보류합니다.

## 속도 필터

각 유효 구간의 관측 속도를 `qᵢ = 구간 증가량 × 6` (%p/시간)으로 계산합니다.

초기 속도는 첫 3개 증가 구간 속도의 중앙값입니다. 이후 구간마다 다음 식을 적용합니다.

```text
α = 1 − 2^(−1/4) ≈ 0.1591
오차 eᵢ = qᵢ − rᵢ₋₁
보정 cᵢ = clamp(eᵢ, −0.5 rᵢ₋₁, +0.5 rᵢ₋₁)
새 속도 rᵢ = rᵢ₋₁ + α cᵢ
```

기본 평활 반감기는 증가 구간 4개, 즉 40분입니다. 한 구간으로 학습 속도가 변할 수 있는 폭은 약 **±7.96%**입니다. 큰 단발 증가를 제한하면서, 높은 속도가 여러 구간 계속되면 그 방향으로 적응합니다. 이는 예측 정확도를 보장하는 신뢰구간이 아니라 급격한 속도 변화를 제한하는 필터 규칙입니다.

## 남은 시간과 시각

```text
남은 사용 시간(시간) = 실제 남은 잔량(%) / 학습 속도(%p/시간)
조건부 소진 시각 = 지금 + 남은 사용 시간
```

실제 잔량이 그대로면 쉬는 동안에도 남은 사용 시간은 유지됩니다. 사용량이 조회되어 증가하면 남은 시간은 줄어듭니다. 소진보다 리셋이 먼저면 '리셋 먼저'로 표시합니다. 절대 날짜로 표현할 수 없는 극도로 작은 속도에서는 소진 날짜를 만들지 않습니다.

카드와 추이 창은 같은 학습 모델을 사용합니다. 모델은 새 화면 스냅샷에서 학습하며, 1초 시계 갱신에서는 이미 학습한 모델로 표시만 갱신합니다.

## 물탱크 움직임

현재 '사용 중' 계정의 0~100% 사이 수위에만 최대 3px, 약 7초 주기의 작은 물결을 넣습니다. 다른 계정의 수면은 수평입니다. 파형의 평균 수위는 실제 잔량 수위와 같고, 별도 수면 테두리는 그리지 않습니다. 숨김·최소화·제거 시 렌더 콜백을 해제하며 최대 20fps로 갱신합니다.

## 검증 범위

동일 잔량에서의 한 시간 휴식·관측 공백, 미완성 3분 급증, 큰 단발 증가, 지속적인 속도 증가, 정수 단위 사용량, 조회 주기 변경, 리셋·오래된 기록·한국 날짜 경계, 실제 렌더 콜백 및 숨김/최소화/복원을 검사합니다. 실제 계정 조회·화면 검증과 합성 재생 검사는 분리되어 있습니다.
